Clothes4Happiness

Prova de Conceito (POC) - Docker e GitHub Actions

Esta aplicação foi desenvolvida para demonstrar a implementação de práticas DevOps na empresa Clothes4Happiness, utilizando Docker para containerização e GitHub Actions para automação de processos de Integração Contínua (CI).

Tecnologias Utilizadas

  • Docker
  • GitHub
  • GitHub Actions
  • CI/CD
  • DevOps
  • HTML

Objetivos da Solução

  • Automatizar processos de desenvolvimento.
  • Padronizar ambientes com containers Docker.
  • Reduzir erros manuais durante implantações.
  • Facilitar atualizações do sistema.
  • Demonstrar integração contínua utilizando GitHub Actions.

Fluxo da Automação

Desenvolvedor → GitHub → GitHub Actions → Build Docker → Atualização do Sistema

✅ Pipeline de Integração Contínua executado com sucesso.
